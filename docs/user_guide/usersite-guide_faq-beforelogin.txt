FAQ: 過剰なアクセスに関する注意事項
ツールやブラウザの拡張機能を利用して、過剰なアクセスを繰り返す行為はお控え下さい。

該当するIPアドレスは予告なしにアクセスが遮断される可能性がございます。

FAQ: 推奨ブラウザを教えてください。
Microsoft Edge、Google Chrome、Safari、Firefoxの最新版が推奨ブラウザです。
他のブラウザでも、サイトの閲覧や操作は可能ですが、表示崩れや動作不順が発生する可能性があります。

上記の推奨ブラウザをご利用されていても、ご利用の環境によっては正常に動作しない場合もあります。
意図しない動作があった場合は、ご利用の拡張機能を無効にする事で改善する可能性もありますのでお試しください。

また、システムのご利用時にはJavaScriptの設定をONにし、ブラウザのCookie（クッキー）を有効にしてください。
Cookie（クッキー）の設定の確認方法については各ブラウザ毎の設定方法をご参照ください。
※Cookieを許可しているにもかかわらず、ログインできない場合は、キャッシュとCookieの削除をお試しください。
（Cookieを削除される場合は、ご自身で十分ご確認いただき、自己責任で実行なさるようお願いいたします。）

FAQ: 団体から案内されたURLで会員サイトを開けません。
推奨環境からのアクセスをお試し下さい。推奨環境については【こちら】をご参照下さい。
 
メール等で会員サイトのURLが案内された場合、URLの後ろの文字が自動的にリンクに含まれてしまい、クリックしても会員サイトが表示されない場合があります。
その場合は、該当するURLをドラッグで選択してコピーし、アドレスバーにペーストしてEnterキーを押してください。

FAQ: ファイルを表示またはダウンロードできません。
ファイルの表示/ダウンロードができない場合、以下の項目を確認して下さい。
 

ブラウザの拡張機能がオンになっている可能性があります。
PDFファイルの閲覧/編集に関連した拡張機能を利用している場合、ファイルをダウンロードできないことがあります。拡張機能をオフにしてダウンロードを試して下さい。
拡張機能の確認方法や設定の変更方法はブラウザのヘルプなどを参照して下さい。
 

ダウンロードリンクに問題がある可能性があります。
受信したメールの本文に記載されているリンクや、外部のホームページに設定されたリンクなどから、直接ファイルをダウンロードすることは出来ません。
スマートコア/アルムネットの対象ページにアクセスして、ページ内のダウンロードリンクからダウンロードを試して下さい。
 

ネットワークにセキュリティ対策などの制限が設定されてる可能性があります。
会社などの組織のネットワークを利用している場合、何らかの制限が設定されている場合があります。異なるネットワークからのアクセスを試して下さい。
 

ブラウザのポップアップをブロックしている可能性があります。
ポップアップをブロックしている場合、ファイルをダウンロードできないことがあります。ポップアップを許可してダウンロードを試して下さい。
ポップアップブロックの解除方法は各ブラウザのヘルプ等を参照して下さい。

FAQ: 入力フォームに文字を入力できません。
入力できる文字の形式が、「半角のみ」や「全角のみ」に制限されているような場合、お使いのパソコンの入力モードによっては入力フォームに文字を入力できないことがあります。
例えば、フォームに入力できる文字の形式が「半角のみ」に制限されている場合、パソコンの入力モードが「全角」になっていると、文字を入力できないことがあります。この場合は、パソコンの入力モードを「半角」に切り換えることで、半角の文字を入力することができます。
テンキーを使って入力する場合も同様です。

FAQ: メールアドレスが無効となり、保存できません。
メールアドレスのフォーマットには国際基準(RFC)があり、こちらに則していないメールアドレスはご登録いただくことができません。

違反例
＠の直前に「.」ドットがある場合　例：xxxx.@xxxxxx
ユーザー名（＠より前の部分）に記号を連続して使用している場合　例：xx..xx@xxxxxx、xx--xx@xxxxxx
ユーザー名の先頭に記号を使用している場合　例：.xxxx@xxxxxx、-xxxx@xxxxxx
携帯電話では、以前これらの設定を無視したアドレスが作成可能であったため、システムにはご登録いただけない場合がありますので、その際は別のアドレスをご登録ください。

FAQ: 会員サイトにログインできません。
ログインができない場合は、以下の内容をご確認ください。
■ IDとパスワードが正しいかご確認ください。　
会員ID・パスワードをメールで受け取った場合は、メールに記載されているID・パスワードのコピー＆ペーストでの入力を試してみてください。
※Windows 7で、右クリックメニューの「貼り付け」を利用した場合、コピーされた内容が正しく貼り付けられないことがあるようです。
その場合は、パスワードをよくご確認の上、直接入力してください。
会員ID・パスワードのお知らせを郵便物で受け取られている場合は、数字の「０」とアルファベットの「O」、
数字の「１」とアルファベットの「l」などの違いに注意して今一度ご確認ください。また、お知らせに大文字で記載されている場合は大文字で、小文字で記載されている場合は小文字で入力する必要があります。
■ IDとパスワードに間違いがない場合は、次のことをご確認ください。　
会員ID（メールアドレス）とパスワードを半角英数で入力されていますか？
    ⇒入力モードは、直接入力又は半角入力にしてください。
Caps Lock（半角大文字入力モード）がかかっていませんか？
　　⇒ キーボードのShift + Caps Lock を押して、Caps Lockを解除して入力してください。
ブラウザがクッキーをブロックする設定になっていませんか？
　　⇒ クッキーを受け入れる（許可する）設定にしてください。
        主なブラウザのクッキーの設定の確認方法については、こちらをご参照ください。
       クッキーを許可しているにも関わらずログインできない場合は、キャッシュとクッキーのクリアを試してください。
      （クッキーを削除される場合は、ご自身で十分ご確認いただき、自己責任で実行なさるようお願いいたします。）
■ 上記を全て確認してもなおログインできない場合は、パスワードの再設定をお試しください。　
※複数のIDで同一のメールアドレスを登録している場合、パスワードの再設定はできません。
   管理者にご連絡ください。
※迷惑メールフィルターをご利用されている場合、当システムからのメールが[迷惑メール]フォルダーに
振り分けられることがあります。メールを受信できるよう、設定してください。

パスワードの再設定は、以下の手順で行います。
ログイン画面にて、「ID・パスワードをお忘れの方はこちら」をクリックします。
「パスワードをお忘れの方はこちら」にチェックを入れ、必要事項を入力し、「送信」ボタンをクリックします。
2で入力したメールアドレスに、「パスワード再設定について」というタイトルのメールが送信されます。
メールに記載されたURLをクリックし、パスワード変更画面をひらきます。URLの有効期限は申請から10分間です。
期限を過ぎると再設定ページの閲覧権限が無効となりますので、その場合は再度申請してください。
新しいパスワードを入力し、「保存」ボタンをクリックします。
ログインページに戻り、新しいパスワードで再度ログインをしてください。
■ パスワードを再設定してもログインできない場合は、次のような理由も考えられます。　
月会費、年会費を支払っている場合、会費のお支払い情報がシステムに届いておらず、一時的に会員サイトが利用できなくなっている可能性があります。お手数ですが、会費のお支払い状況をご確認のうえ、事務局にお問い合わせください。
ご利用のパソコンの日付・時間が影響している可能性があります。以下の手順で日付と時刻をご確認ください。
マイコンピュータを開きます。
コントロールパネルを開きます。
【日付と時刻】をクリックして正しい日時に変更します。
職場や学校内など、ファイアウォールやプロキシサーバーを利用したネットワークから接続していると、ログインできないことがあります。職場や学校のネットワーク管理者にお問い合わせください。
「このアカウントは現在使用できません」とメッセージが表示されている場合は、ログインに連続で失敗したため、
一定時間ログインすることが出来ません。時間をおいて再度お試しください。お急ぎの場合は管理者にご連絡ください。
セキュリティ等の理由により、システムにてIPがブロックされている可能性があります。時間が経過しても改善しない場合は、管理者にご確認ください。

FAQ: 会員サイトから勝手にログアウトしてしまいます。
会員サイトから勝手にログアウトしてしまう原因として以下のものが考えられます。

タイムアウト
1時間以上何も操作（登録ボタンや編集ボタンをクリック、ページの切り替えなど）をしない状態が続くと、ログインがタイムアウトとなり、次に何か操作を行ったタイミングで、自動的にログイン画面に切り替わります。

不安定なネットワーク接続環境
スマートコアシステムはアクセスするネットワーク環境（IPアドレス）が途中で変更されると、セキュリティの関係上システムからログアウトする仕組みになっています。職場や外出先から利用している場合、ネットワークの設定によりIPアドレスが頻繁に変わる設定を行っている場合があるため、ご自宅などネットワーク環境が安定している環境下で、ご利用ください。

ブラウザ設定
過去にアクセスした際にブラウザに読み込まれた設定等により、会員サイトへのアクセスに支障が発生している可能性が考えられます。キャッシュをクリアすることで問題が解消する場合があります。。

 

キャッシュの削除方法は、ご利用のブラウザのヘルプもしくはサポートをご参照ください

FAQ: クッキー情報について
当システムでは、以下のようなクッキーを使用しています。

 

お客様は、ブラウザの設定により、クッキーの受け取りを拒否したり、クッキーを受け取ったときに警告を表示させたりすることができますが、拒否された場合には、一部のサービスを受けられない場合がありますことをご了承ください。

 

必須クッキー（Strictly Necessary Cookies） 
お客様が会員サイトを閲覧したり、その機能を利用したりするために不可欠のものです。これらのクッキーを拒否すると、会員サイトが利用できなくなる場合があります。

 

名称：	user_alumnet_session
プロバイダ：	Smartcore System
目的：	ログイン状態の維持
種類：	ファーストパーティ
継続期間：	セットアップ～ブラウザクローズまたは更新から60分
名称：	csrf_cookie_name
プロバイダ：	Smartcore System
目的：	CSRF（Cross Site Request Forgery）対策
種類：	ファーストパーティ
継続期間：	セットアップ～ログアウトまたは更新から120分
 

機能性クッキー (Functionality Cookies)
画面上にアラートを表示する時やリスト画面を表示する時などに、システムの機能を補助するために使用します。また、サイトの表示言語、会員リストやメッセージ受信ボックスにおけるアイテムの選択など、ユーザーが行った選択を記憶するためにも使用します。

なお、これらのCookieが収集した情報によって個人が特定されることはありません。
 

 パフォーマンスクッキー (Performance Cookies)
ウェブサイトの利用状況についての情報を収集するために使用されますが、当システム固有のクッキーではありません。管理者ユーザー（会員サイトの運営者）が、googleアナリティクスを利用して会員サイトでのユーザーの操作を測定している場合にのみ、googleのクッキーが使用されます。

 

上記の他、管理者側で外部連携設定を行っている場合は、外部連携先のサードパーティクッキーが使用されることがありますが、外部連携設定を行っていない場合は、サードパーティクッキーが使用されることはありません。
