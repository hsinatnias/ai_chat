FAQ: PDFファイルが表示できません/PDFファイルにアクセスすると別のページに遷移してしまいます。
PDFファイルの閲覧/編集に関連した拡張機能を利用している場合、ファイルを正しく表示/ダウンロードできないことがあります。拡張機能をオフにしてダウンロードするか、別のブラウザ/端末から操作をお試し下さい。
拡張機能の確認方法や設定の変更方法はブラウザのヘルプなどを参照して下さい。

FAQ: ファイルを表示またはダウンロードできません。
ファイルの表示/ダウンロードができない場合、以下の項目を確認して下さい。
 

ブラウザの拡張機能がオンになっている可能性があります。
PDFファイルの閲覧/編集に関連した拡張機能を利用している場合、ファイルをダウンロードできないことがあります。拡張機能をオフにしてダウンロードを試して下さい。
拡張機能の確認方法や設定の変更方法はブラウザのヘルプなどを参照して下さい。
 

ダウンロードリンクに問題がある可能性があります。
受信したメールの本文に記載されているリンクや、外部のホームページに設定されたリンクなどから、直接ファイルをダウンロードすることは出来ません。
スマートコア/アルムネットの対象ページにアクセスして、ページ内のダウンロードリンクからダウンロードを試して下さい。
 

ネットワークにセキュリティ対策などの制限が設定されてる可能性があります。
会社などの組織のネットワークを利用している場合、何らかの制限が設定されている場合があります。異なるネットワークからのアクセスを試して下さい。
 

ブラウザのポップアップをブロックしている可能性があります。
ポップアップをブロックしている場合、ファイルをダウンロードできないことがあります。ポップアップを許可してダウンロードを試して下さい。
ポップアップブロックの解除方法は各ブラウザのヘルプ等を参照して下さい。


FAQ: ファイルのダウンロード方法を教えて下さい。
管理者がアップロードしたファイルをダウンロードすることができます。
以下の手順でファイルをダウンロードします。
表示されているメニューから「ファイル」をクリックしファイルリストを表示します。
※メニュー表示名は異なる場合があります。機能のコードは"C231"です。
任意のタイトル、カテゴリの「詳細を見る」ボタンをクリックします。または画面上部のファイル検索窓に文言を入力し検索ボタンをクリックし、検索結果で表示されるファイル名をクリックします。
※検索対象はファイル名、ファイルの説明文となります。カテゴリ及びタイトルの名称と説明文については検索対象に含まれません。
任意のファイルの「ダウンロード」アイコンをクリックします。
※会員がファイルをアップロードすることはできません。
※団体の運営方針により、ご利用いただける機能が異なりますのでご注意ください。
