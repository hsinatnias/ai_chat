Admin — Ingest documents

This admin panel requires an API key. For local testing you'll be prompted for the key once and it will be saved to sessionStorage.

Modules are logical KB compartments. Upload + ingest operate per-module. Deleting a module only removes the DB record; to remove vectors use "Delete Qdrant collection for module".

After upload, click "Trigger ingest" to run server-side ingest for the selected module.
